ZELABAIRRO - IA & CHATBOT - COMO RODAR E REPLICAR OS RESULTADOS
Turma 1TDSPV - Global Solution 2026/2

Requisito: Python 3.11 ou mais novo (modelos treinados com Python 3.12 e scikit-learn 1.9.1).
Para conferir: python --version

Rode UM comando por vez. Linhas que começam com # são explicações (não digite).

======================================================================
PARTE 1 - INSTALAR (só na primeira vez)
======================================================================

--- WINDOWS (PowerShell) ---

# 1. Entre na pasta do projeto (troque pelo seu caminho). É a pasta que contém app.py:
#    se ao extrair o ZIP aparecer uma pasta dentro de outra, entre na mais interna.
cd C:\Users\SeuNome\Downloads\zelabairro-ia

# 2. Confira se está na pasta certa: devem aparecer app.py, requirements.txt, models, chatbot
dir

# 3. Crie o ambiente virtual
python -m venv .venv

# 4. Ative o ambiente (aparece "(.venv)" no começo da linha)
.venv\Scripts\activate

# Se der erro "a execução de scripts foi desabilitada", rode a linha abaixo,
# responda S e repita o passo 4:
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

# 5. Instale as dependências (leva alguns minutos)
pip install -r requirements.txt

--- MAC / LINUX (Terminal) ---

cd ~/Downloads/zelabairro-ia
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

======================================================================
PROBLEMAS COMUNS
======================================================================

* "python não é reconhecido": instale o Python em python.org e marque
  "Add Python to PATH" na instalação. Depois feche e reabra o terminal.
* "No module named ...": o ambiente não está ativado (falta o "(.venv)").
  Rode o activate de novo.
* /health responde 503 ou erro ao carregar o modelo: confira se a pasta models
  tem modelo_prazo.joblib e modelo_atraso.joblib, e se o scikit-learn é o 1.9.1:
      pip show scikit-learn
* "Address already in use" / porta 5000 ocupada: feche o outro app.py
  ou rode em outra porta:
      Windows:      $env:PORT="5001"; python app.py
      Mac/Linux:    PORT=5001 python app.py
